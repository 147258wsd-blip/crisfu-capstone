Portfolio & Blog REST API

The Express + MongoDB back-end behind the portfolio site. 22 endpoints, JWT authentication, ownership checks on every write. This page talks to the deployed API from your browser — the exact same cross-origin requests the React client makes.

Base URL

GET  https://crisfu-api-ngpxktjcws.cn-hangzhou.fcapp.run/api

This page is the human-readable reference for that API — the API itself is the base URL above, which is what an HTTP client calls.
Heads-up: Alibaba Cloud Function Compute adds Content-Disposition: attachment to every response from its default domain, so pasting the URL into the address bar downloads a .json file instead of rendering it. XHR/fetch ignores that header, which is why this page (and the site) can read it normally. The buttons below prove the API is live.

Endpoints everything is mounted under /api

MethodPathAuthPurpose / expected body
GET/health—Uptime probe. {success,status,uptime,at}
GET/—Machine-readable map of every route.
POST/users/register—{username,email,password} → 201 + JWT. 409 on duplicate, 400 on weak password.
POST/users/login—{email,password} → 200 + token. One message for both failure cases.
GET/users/meBearerToken re-validation; the SPA calls it on every page load.
GET/projects—All projects. ?cat=web filters by category.
GET/projects/:id—One project. Malformed id → 404, not a cast error.
POST/projectsBearer{title,description,category,tags,link,year}. Owner comes from the token.
PUT PATCH/projects/:idBearer + ownerPartial update. 403 for anyone who is not the owner.
DELETE/projects/:idBearer + ownerDelete. 403 for non-owner, 200 for the owner.
GET/blog—Posts, author populated. ?tag= ?q=
GET/blog/:id—One post plus commentCount.
POST/blogBearer{title,excerpt,body,tags,readTime}
PUT PATCH/blog/:idBearer + authorUpdate. 403 for a different user.
DELETE/blog/:idBearer + authorDeletes the post and its comments together.
GET/blog/:postId/comments—Comments for one post, author populated.
POST/blog/:postId/commentsBearer{body} — author taken from the token, never the body.
DELETE/blog/:postId/comments/:commentIdBearerComment author or the post author may delete.
POST/contact—{name,email,message} → 201. 400 on an invalid email.
GET/contactBearerAdmin inbox, newest first.
PATCH/contact/:id/readBearerMark one message read.
GET/admin/statsBearerFour counters for the dashboard.
GET/admin/activityBearerMerged feed of the ten newest events.

Every failure has the same envelope: { success:false, message:"…", errors:{ field:"…" } }.

Try it with curl

curl https://crisfu-api-ngpxktjcws.cn-hangzhou.fcapp.run/api/projects TOKEN=$(curl -s -X POST https://crisfu-api-ngpxktjcws.cn-hangzhou.fcapp.run/api/users/login \ -H "Content-Type: application/json" \ -d '{"email":"cris@crisfu.dev","password":"crisfu2026"}' | sed 's/.*"token":"\([^"]*\)".*/\1/') curl https://crisfu-api-ngpxktjcws.cn-hangzhou.fcapp.run/api/users/me \ -H "Authorization: Bearer $TOKEN"
